## Method

Both crates are #![no_std] + alloc libs whose panic handler and global
allocator are supplied by consumers. A throwaway harness crate (minted in
/tmp by the script, never committed) pub use-re-exports each crate's full
public API so every pub item is a linker root, supplies minimal disclosed
no_std link glue (panic handler + never-called GlobalAlloc, ~0 bytes), and
mirrors the repo release profile (lto = thin, codegen-units = 1). The
COMBINED figure links both crates together so shared core/alloc glue is
counted once; per-crate figures come from single-crate harnesses and
therefore each include one copy of that glue.
