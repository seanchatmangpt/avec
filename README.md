# avec

avec is a freestanding, branchless Apache Arrow columnar substrate: an in-memory columnar
vector library (`avec-arrow`) plus branchless Parquet persistence kernels (`avec-parquet`),
both `no_std` + `alloc` with zero external dependencies. Buffers are 64-byte aligned at
allocation, scan kernels compile to zero conditional branches (proved on the compiled
machine code, not asserted), and arrays cross language boundaries through the Apache Arrow
C Data Interface as zero-copy `ArrowArray` / `ArrowSchema` pairs with atomic
release-swap single-release ownership.

The repo is ontology-driven: the Arrow layout ground truth (format codes, buffer counts,
slot widths), the C header ABI, and even the release version string are generated by
[ggen](https://github.com/seanchatmangpt/ggen) from an RDF ontology, and the generated
files carry their regeneration recipe in their headers. Layout dispatch code
(`crates/avec-arrow/src/generated_layout.rs`), format-code macros
(`include/avec_format_codes.h`), the C Data Interface header (`include/avec_c_data.h`),
and the version constant (`crates/avec-arrow/src/generated_version.rs`) are projections;
the kernels in `crates/avec-arrow/src/*.rs` are the hand-written irreducible residue.
Every quality claim in this README is backed by a command in the Receipts section.

## Generated files: ontology in, code out

`ggen sync run` projects four generated surfaces from the avec-pack ontology:

```console
$ ggen sync run          # renders:
#   include/avec_c_data.h
#   include/avec_format_codes.h
#   crates/avec-arrow/src/generated_layout.rs
#   crates/avec-arrow/src/generated_version.rs
```

The pack is pinned in `ggen.toml` (`avec-pack = { path = "../ggen-marketplace/packs/avec-pack" }`)
and content-hashed in `ggen.lock` (`blake3:3e5357...19ae7e`, 2 subjects). The four files
are marked `do not edit` in their headers; hand edits are overwritten on the next sync.
Gate 0 re-runs the sync twice and requires byte-identical output, then compiles the C
header freestanding (`cc -std=c99 -ffreestanding -Wall -Wextra -pedantic`).

## Quickstart

```console
$ make test        # cargo test --workspace
$ make gates       # gate0 -> gate1 -> gate2 -> gate3, fail-closed
$ cargo run --release -p bench     # CTQ-1 throughput + alloc count, single command
```

Prerequisites: Rust (stable, edition 2021), `python3` with `pyarrow` (Gate 3 imports the
exported batch through `pa.Array._import_from_c`), `ggen` on `PATH` (Gate 0), and
`xcrun llvm-objdump` (Gate 1). No Makefile-step needs network access after the first
`cargo build`.
